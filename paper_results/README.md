# Frozen manuscript result tables

`paper_results/tables/` contains the compact numerical summaries used to check the current manuscript version. Detailed group-level and Monte-Carlo trial outputs are generated by the experiment scripts and written under `results/`.

Main mapping:

- `exp01_round_ablation_summary.csv` — round-count ablation
- `exp02_k_sensitivity_summary.csv` — K sensitivity and runtime tradeoff
- `exp03_progressive_access_summary.csv` — progressive key release
- `exp04_group_loss_summary.csv` — encrypted-group loss
- `exp05_dataset_aggregate.csv` — USC-SIPI/Kodak validation
- `exp06_controlled_baselines_summary.csv` — controlled cipher/representation baselines
- `exp06_controlled_baselines_capabilities.csv` — access-capability comparison
- `exp07_progressive_three_images_summary.csv` — Clock/Aerial/Portrait visual study

Fresh runs write to `results/` and do not overwrite these reference summaries.
